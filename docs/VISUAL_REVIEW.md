# Визуальное направление

Бордовый акцент, молочная светлая основа и угольная тёмная. Изумрудный ограничен демонстрационным приложением с собственным визуальным контекстом. Лампа — сгенерированный демонстрационный объект, не товар и не клиентская работа. Знак K выполнен в SVG. Manrope поставляется локально через Fontsource.

При просмотре исправлены: лишняя кнопка меню на десктопе, длинное название дня, крупные мобильные заголовки, узкие описания услуг, разные высоты демонстраций, изменение высоты результата при выборе времени, читаемость текста до завершения появления, подпись подсветки.

Движение: смена темы 650 мс, появление секций, проявление слов, отклик стрелок и выбранного времени, раскрытие FAQ. Бесконечных декоративных анимаций нет. При reduced motion пространственные эффекты отключаются, текст остаётся видимым.

## Modern Web Guidance

- `interactive-content-reveal`: блики не перекрывают элементы и не скрывают содержимое; “pointer-events: none” и полностью доступный основной интерфейс.
- `motion`: длительное движение можно остановить, при reduced motion оно отключается; “Provide a pause mechanism”.

- `same-document-transitions`: я меняю палитру через startViewTransition с сохранением фокуса и мгновенным запасным вариантом. “The View Transitions API is designed for progressive enhancement.”
- `motion`: я использую конечные эффекты opacity/transform и учитываю reduced motion. “Keep the final state”.
- `color`: я сохраняю контраст и текстовые/геометрические признаки состояния. “Don't use color alone”.
- `animate-to-intrinsic-sizes`: я анимирую нативный details через проверку поддержки, иначе он открывается сразу. “One end of the transition must be a fixed length or percentage”.
- `component-specific-light-dark-theme`: я задаю демонстрационному приложению собственные фон, текст, accent-color и color-scheme. “Do not set `color-scheme` on elements without a background”.

Первоначальные браузерные сценарии прошли на семи ширинах в обеих темах. Последующая визуальная доводка проверяется прямым просмотром. Исходные оценки Lighthouse не выдаются за повторную проверку новой палитры. Намеренный noindex снижает SEO-оценку локального стенда.
